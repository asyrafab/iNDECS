# CLAUDE.md

This project's binding instructions live in [AGENTS.md](AGENTS.md). Read it, plus
`docs/DESIGN-DIRECTION.md`, before writing or changing any UI.

Short version: Modernist visual system — Archivo, zero radius, 2px rules, flush
left, one red accent (#ec3013) from `public/css/tokens.css`. Never hard-code a
colour, font or spacing value. Four departmental applications on one shared core:
iNDECS Perancang, Bangunan, Kejuruteraan, Landskap.
