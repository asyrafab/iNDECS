# ADR-382: Small edging on the garden walking path

Date: 2026-11-12. Status: accepted by owner.

## Decision

Refine ADR-381's circular garden with narrow stone edging along both sides of the walking path. Reuse the existing untinted stone texture at a smaller scale for the edging, with restrained joints and a light contact seam at the grass edge. Keep the edging within the existing garden footprint so grass, path and building remain connected.

All edging belongs to the existing material garden group and shares its reveal/fade. The approved final logo, timing, planting and accessibility fallbacks are unchanged. No additional image dependency or processing is introduced. SVG radii, stroke widths and joint lengths describe the illustration geometry; contact/joint colours use the existing material-shadow token.
