# ADR-372: Official AIRS logo in the application chooser

Date: 2026-11-06. Status: Accepted by the programme owner.

## Decision

Replace the generic search icon on the AIRS chooser entry with AIRS's unchanged
official compact logo, copied from the cooperating AIRS application's
public/assets/brand/airs-icon.svg. The source app uses that asset for its compact
brand identity and favicon. Keep its original gradients, colours and geometry;
these are an owner-requested identity exception, not additional UI accents.

Use the same 64 px identity area as the department entries, without the generic
rounded tint container or an added shadow. The adjacent AIRS name provides the
accessible label, so the image is decorative. Keep the AIRS destination and
existing administrator visibility checks unchanged. Record provenance beside
the copied asset. Do not rename, recolour or regenerate the official logo.
