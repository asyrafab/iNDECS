# ADR-388: Draft trash action and document popup refinements

Date: 2026-11-16

Status: Accepted (owner request)

## Decision

Fail saya cards have a small red trash icon at the upper right, retaining an
accessible name, tooltip, confirmation and existing removal eligibility. Remove
the redundant Sambung cue; the whole-card native link remains. Other removal
surfaces retain their labelled buttons.

Reading dots are horizontal and keep their cumulative looping sequence. Enlarge
the attention triangle to visually match the other status shapes. Remove the
legend, preserving accessible status names and tooltips. Document description
dialogs enter with a short fade, rise and scale animation using shared tokens;
the existing reduced-motion controls disable it. No upload or review rules change.
