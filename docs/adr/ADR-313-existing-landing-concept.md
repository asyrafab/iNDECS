# ADR-313: Adopt the existing iNDECS landing concept

Date: 2026-10-29. Status: Accepted. Supersedes ADR-312's page composition.

## Context

The owner identified the established concept in the iNDECS Bangunan working
folder, `docs/mockups/index.html`, and requested it replace the new landing page.

## Decision

Use the concept's navigation, navy skyline hero, headline, status-lookup placement,
six service cards and service-finder callout. Adapt presentation to the binding
shared teal tokens, Google Sans, crest-first identity and local Lucide icons.
Retain a finite three-square introduction with a replay control; it never blocks
interaction and is suppressed by both motion preferences. No gradients or glows.

Replace the concept's status simulator with an explicitly unavailable control.
Service cards link to local guidance, not non-existent submission endpoints.
Keep existing account routes and authenticated entry behaviour. Public tracking,
fees and submissions remain future capabilities; no fabricated results or dates.

## Consequences

The guest page follows the owner's existing concept while truthfully reflecting
implemented services. Remove superseded landing CSS. Verify mobile layouts,
themes, motion, navigation, account links and protected-route regressions.
