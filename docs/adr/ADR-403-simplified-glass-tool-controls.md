# ADR-403: Simplified glass tool controls

Date: 2026-11-18. Status: accepted under the owner request.

Use a bare drag grip without a visible button box (keep its accessible name, hit area and keyboard focus). Shorten the collapsed primary score label to Skor; expanded detail retains advisory context. Remove the position-reset control, Home reset shortcut and colour legend. Keep pointer/arrow movement, Escape cancellation, unresolved navigation and viewport clamping.

Replace the outer black/status outline with a thicker white glass border through tokens, preserving score colours, transparent finish, capsule morph and isolated expansion. No workflow or data changes.
