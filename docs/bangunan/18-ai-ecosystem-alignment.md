## Confirmed agent identities

| Agent | Full name | Responsibility |
|---|---|---|
| AMIRA | AI Municipal Interaction & Response Assistant | Application/SOP guidance and permitted result presentation; current backend remains read-only with bounded proposals. |
| MATRIX | MBSP AI for Text Recognition & Information eXtraction | Document/image interpretation, structured extraction, comparison and evidence-backed drafts/reports. |
| MINDA | MBSP Intelligence Network for Data Analytics | Internal cross-system investigation, synthesis, analytical/spatial intelligence and advice. |

Technical review, data quality stewardship, observation and operational coordination remain separate roles. Agent names are not model selections or proof of enabled integrations.

## Common boundaries

MATRIX is established as a planning project, not an AIRS rename or code extraction. AIRS retains its existing review/extraction engine, rules, evidence, findings and audit. iNDECS retains official identity, records, payments, workflow, assignment/SLA, decisions and letters. The ecosystem manages agent configuration and AI coordination, not competing business state. Human officers retain approval/professional authority.

Public sessions and their processing chains cannot invoke internal MINDA. Access is checked at source retrieval, tools, findings reuse and export. Preserve evidence, source versions, validation and uncertainty. Retained conversations do not automatically retrain model weights; candidate lessons require evaluation before published behaviour changes.

The existing free-precheck/payment/accepted-submission gates in iNDECS/AIRS remain unchanged. MATRIX naming cannot enable paid/cloud AI, technical compliance or readiness scoring in free precheck. No API, queue, database, credential, model setting, UI or production deployment is changed by this documentation.

## Project-specific application

This folder is a working documentation area for **iNDECS Bangunan**, not a renamed production module. Canonical programme documentation is in iNDECS/docs/bangunan and is aligned alongside this copy. AMIRA helps applicants/officers with procedures; MATRIX can supply future extracted fields and documentary comparisons; AIRS retains technical review; MINDA can supply authorised internal synthesis. Old descriptions of a standalone iNDECS AI layer are earlier implementation proposals: route shared agent responsibilities through explicit adapters as designed, without moving code or bypassing payment/validation.
