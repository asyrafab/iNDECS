# Official AIRS compact logo

airs-icon.svg is an unchanged copy of the cooperating AIRS application's
public/assets/brand/airs-icon.svg, from the owner's local Plan Review workspace.
That source asset is used by AIRS for its compact brand and favicon. Its source
README identifies it as the official supplied AIRS icon-only vector export.

Use as the AIRS application chooser identity (ADR-372). Retain its colours,
gradients, opacity and geometry. Do not recolour it through iNDECS tokens or
replace it with a generic Lucide search icon. Use a decorative empty alt when an
adjacent AIRS label identifies the link. Its native visual treatment is a narrow
owner-requested brand exception; common UI actions and accents stay unchanged.
