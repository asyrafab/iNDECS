# Esri logo — E-Plan Submission identity

ADR-375 connects the tile to the owner-supplied
https://spgis.mbsp.gov.my/ePlanSubmission, retaining existing visibility checks.
This supersedes the earlier unavailable/no-destination delivery note below.

ADR-374 supersedes the original white identity ground described below. The
current chooser treatment is transparent and borderless. A theme token shows
black on light tiles and white on dark tiles using the unchanged SVG geometry.

Esri's brand guidance identifies its black/white globe logo and requests that
logos be used in their entirety, without modification, with attribution to Esri:
https://www.esri.com/en-us/about/media-relations/b-roll.

Used at the programme owner's request to identify the Esri spatial subsystem
on the E-Plan Submission chooser tile (ADR-373). Preserve the full globe and
wordmark, source colour, geometry and aspect ratio. The white identity ground
is supplied by token-based CSS for legibility across themes; the SVG is not
recoloured. The asset does not imply that Esri endorses iNDECS, and the chooser
entry remains unavailable with no fabricated destination. No external request
is needed to display the locally stored logo.
